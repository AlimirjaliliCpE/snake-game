# 🐍 Snake Game

A simple and classic Snake Game developed with **Python** and **Pygame**.

## 🎮 Features

* Classic Snake gameplay
* Score system
* Random food generation
* Collision detection
* Restart functionality
* Keyboard controls
* Grid-based game system

## 🛠️ Technologies

* Python
* Pygame

## 🚀 Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd snake-game
```

Install the required package:

```bash
pip install -r requirements.txt
```

Run the game:

```bash
python main.py
```

## 🎯 Controls

| Key | Action     |
| --- | ---------- |
| ↑   | Move Up    |
| ↓   | Move Down  |
| ←   | Move Left  |
| →   | Move Right |
| R   | Restart    |
| ESC | Quit       |
